## 对接入方案的结论

新来源表继续保存 `software` 原始字符串，包括名称内已有的版本号，不将此次样本写成数据库 `choices`。后续遇到新的软件名称或名称版本也原样保存、展示；本站 `VideoModel.software` 仍由实际录像文件解析确定。接入范围见[官方 API 接入方案](SAOLEI_API_IMPORT_PLAN.md)。

本站导入采用软件白名单，仅接受原字符串精确匹配的 `Clone`、`Vienna`、`Arbiter`、`元扫雷3.3.4`。`Saolei.wang` 和其他白名单外取值仍原样保存、展示，但单条、批量及全站重建时均跳过导入，不下载录像文件；新名称或其他版本名称不会自动获得导入资格。此业务筛选与上游审核 `status` 无关，跳过数量单独汇总。
