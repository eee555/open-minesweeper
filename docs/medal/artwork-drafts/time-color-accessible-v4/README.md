## 显示调整

原曲线将较亮的原图区域迅速向白色推，较大亮面主导了整体观感。新曲线让主要亮度范围映射到所选颜色附近：中间切面保留深浅变化，原图极亮区域才获得较强高光。不再给全部边缘叠加白色轮廓；浅色背景用轻微深色轮廓辅助，深色背景使用较弱的浅色轮廓辅助。

`tone.ts` 为实际使用的曲线，生成 256 点的 RGB 查找表，不处理 alpha。参考节点：输入亮度 0.75 接近所选原色，0.90 向白色混入约 2%，0.96 混入约 5%；0.98 以上逐渐增加少量强高光。暗面通过较低的颜色强度保留厚度。

## 检查

[曲线与源图像素检查记录](./exports/tone-verification.json)直接引用实际查找表，在原图 alpha > 128 的像素上采样。以输出颜色向白色方向偏移超过 20% 为诊断条件，相应像素比例由上版约 45.16% 降至约 3.88%；深蓝接近所选色值的像素比例由约 9.27% 提高到约 42.33%。该统计包括暗边和碎片，属于源图亮度诊断，不等于人工分割的主体面积，也不替代浏览器渲染验收。

检查也覆盖 RGB 表值边界、明暗单调性、五种默认色及黑白边界输入，确保阴影和高光没有反向跳变。源图与独立星级继续原样内嵌，离线页无需服务器。
