# 五色平衡方案 v3

按用户提出的深蓝、中蓝、浅紫、浅橙、中红方向重做默认方案，兼顾常规色觉中的色相差异及色觉模拟中的区别。此方案取代上轮 Cividis 默认推荐，上轮离线文件保留作历史参考。

[打开新版离线 HTML](./exports/time-color-accessible-preview-offline.html)。

五档依次为：深蓝 `#244A86`、中蓝 `#4C91C7`、浅紫 `#CCB8E3`、浅橙 `#F2CE9B`、中红 `#B34A55`。蓝色之间拉开明暗；浅紫特意提亮以减少红色觉缺失模拟中与中蓝的接近；浅橙偏暖而明亮，中红更深。不再要求五档亮度一直递增，成绩先后由常驻色档编号、Sub 门槛和完整名称共同表达。星数继续仅表示难度。

用 Machado 2009 的 severity 1.0 矩阵在线性 RGB 中检查红／绿／蓝色觉缺失模拟，见 [基色比较记录](./palette-check.json)。记录给出各组基色的 CIELAB 距离，只作设计诊断；金属高光、小尺寸和个人视觉差异需要结合实际预览检查，不宣称所有类型色盲都能单靠颜色区分。[W3C 用色指南](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)要求颜色之外的辨识线索，本页保留编号与文字。

继续支持五档独立选色、单门槛覆盖、本地保存、恢复默认、JSON 导入导出、灰度与色觉模拟。真实自定义不会因默认更新而被覆盖；如果仅保存了无门槛覆盖的上轮默认五色，新审阅页自动显示本轮方案。若载入的是自己的自定义，状态会提示可点“恢复默认”查看本轮推荐。

原图、金属明暗着色方式及左上星级位置沿用 v2。初级 Time 的 11 个门槛分组仍待审阅，正式站点组件与其他系列映射尚未切换。

重建：运行本目录 `build_review.mjs`，再运行 `check_palette.py` 生成基色检查记录。前端共享偏好服务为 `front_end/src/services/medalPalette.ts`，配置格式和存储键保持兼容。浏览器自动化受本地文件 URL 策略限制，本轮未重新执行浏览器交互验收；类型与偏好服务测试另行执行。
