# 色觉友好配色与逐阶段自定义 v2

按用户反馈，旧版青绿／蓝／紫／橙／玫红停止作为推荐方案，保留历史审阅文件。本版提供新的默认色阶与可操作的前端自定义审阅页。

- [直接打开离线 HTML](./exports/time-color-accessible-preview-offline.html)。
- [默认效果浏览器截图](./preview-light.png)、[配色及门槛配置](./review.json)。
- [资源校验记录](./exports/export-manifest.json)。

## 新的默认方案

参考 Cividis 的顺序色阶，采用深蓝 `#00224E`、蓝灰 `#434E6C`、中灰 `#7D7C78`、卡其 `#BCAE6C`、亮黄 `#FEE838`。五档基色亮度逐档上升，用于有顺序的成绩档次。Cividis 的原始研究主要针对常见红绿色觉差异优化，不能据此保证所有色觉类型、屏幕和金属亮暗面都同等可辨。[原始研究](https://doi.org/10.1371/journal.pone.0199239)。

所有预览常驻色档编号、Sub 门槛和完整可访问名称；灰度或自定义成同色时也能读出成绩。左上独立星级继续表示难度，与五个成绩色档分开。文字等额外线索依据 [W3C Use of Color](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)，本稿不宣称通过整站 WCAG 认证。

页面提供红、绿、蓝色觉缺失模拟与灰度，使用 [Machado、Oliveira、Fernandes 2009](https://pubmed.ncbi.nlm.nih.gov/19834201/) 的 severity 1.0 矩阵，在线性 RGB 中运算。模拟仅用于辅助审阅，不能取代实际用户检验。

## 可直接使用的自定义功能

五个色档分别支持取色器、HEX 输入和单档恢复默认。每个初级 Time 门槛也能单独覆盖颜色，优先级为“指定 code 与 stage 的覆盖 → 已审阅的色档颜色”。单独设色不改变色档归属、成绩数值或门槛；点“跟随色档”取消覆盖。

有效修改即时预览并尝试保存到浏览器；存储被禁用或配额失败会明确提示，仍可导出 JSON。支持 JSON 导入、导出和恢复全部默认。导入先完整校验，失败不覆盖当前配置。只接受五个 `#RRGGBB` 色值、版本 1 与有效的 code／正整数门槛配置，限制文件大小和条目数量。

共享配置逻辑已实现于 `front_end/src/services/medalPalette.ts`，本审阅页直接打包引用，避免为演示维护另一套规则。存储键为 `medal-appearance-colors-v1`，配置示例：

```json
{
  "version": 1,
  "colors": ["#00224E", "#434E6C", "#7D7C78", "#BCAE6C", "#FEE838"],
  "stages": {"ability.time.b": {"20000": "#336699"}}
}
```

这是观看者本人的显示偏好；正式接入时不改被查看玩家的数据，不发放称号或修改成绩。单文件本地页与正式网站存储源不同，需使用 JSON 转移，不能承诺本地预览的设置自动同步到网站。

## 模板与显示

原 v3 破境 PNG 和一／二／三颗星 PNG 均逐字节内嵌。SVG 展示滤镜依据原图亮暗建立金属色调，保留切面与 alpha；未生成或替换新的源图片，也没有烘焙各门槛成品。星级位置沿用 difficulty-overlays-v2，主体保持 100% 原画布、星级左 4% 上 0% 宽高 36%。

五色大图可切换星级检查构图，初级 Time 的 11 个门槛固定一星；不据此声称已制作中高级门槛映射。原分组 Sub20／15／12、Sub10／8、Sub6／5、Sub4／3、Sub2／1 继续作为待审阅提案。

本轮着色只用于全金色 Time 造型。正式处理含 NF 蓝色副章、审核标记等的模板，需使用明确的可着色层或遮罩，让固定色副章保持独立；不能将整图滤镜直接推广到全部系列。

## 正式前端接入安排

沿用用户先审阅设计、再接入正式展示的流程。本轮已提供可操作的自定义前端和共享偏好服务；生产的 `MedalArt.vue`、正式发布图和未审阅的各系列门槛映射尚未切换。

定稿后，在“设置 → 外观 → 勋章配色”放置同一组五档选色与高级门槛覆盖入口，使用项目现有 `BaseColorPicker`。用响应式偏好读取共享服务，保持勋章页、个人资料佩戴区和名字提示一致；只影响当前观看者，不新增逐玩家请求。先补全各系列门槛到色档的明确映射，以及可着色层，再接入统一渲染器。未映射门槛保持中性，不按难度、序号或排行榜猜测色档。

## 重建与验证

安装了项目现有依赖时，运行 `node docs/medal/artwork-drafts/time-color-accessible-v2/build_review.mjs`，生成可独立打开的 `index.html` 和离线导出。图片、脚本与样式均内嵌，无服务器或 CDN 依赖；研究链接仅作说明来源。

配置服务测试覆盖门槛覆盖优先级、未知映射、非法导入、存储失败、持久化与损坏配置恢复。浏览器实际显示使用本目录的预览截图检阅。
