# 共享难度星级源资源

当前正式使用的独立透明 PNG：`one-star.png`（初级）、`two-stars.png`（中级）、`three-stars.png`（高级，上方一颗、下方两颗）。保留共同方形画布，不分别裁切星组。

布局与源图 SHA256 见 [manifest.json](./manifest.json)。星级左 2%、上 0%、宽高 32%。主体保持居中：通明占 74%，精工占 80%，其他单难度能力系列占 100%。已检查 8 类 × 3 难度的可见区域不重叠。

生成器统一输出 `public/assets/medals/difficulty/{b,i,e}.webp`，每张 64×64、不超过 2KiB。网页只引用这些压缩发布图。历史审阅文件留在本地，不作为构建依赖。

难度由外观配置明确指定。三阶精工及其他跨难度称号不自动附加三星，无单一难度的称号不附加星级。
