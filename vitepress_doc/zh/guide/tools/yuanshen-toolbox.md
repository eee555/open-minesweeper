# 元神工具箱

元神工具箱是一个 Windows 桌面工具，在本地读取元扫雷（`.evf`）与阿比特（`.avf`）录像，统计 PB、每日练习与 LSF，并把成绩上传到本站。

作者是本站玩家（扫雷网 #27415、开源扫雷网 #3）。**这是第三方工具，与开源扫雷网、元扫雷、阿比特均无隶属关系**：它只读本地录像，只调用本站的公开接口，不上传录像之外的任何数据，也不会修改或删除任何录像文件。

## 下载

到 [Releases](https://github.com/Corday-nkusky/yuanshen-toolbox/releases/latest) 下载最新的 `YuanshenToolbox.exe`（单文件，约 27 MB）。免安装，不需要 Python，双击即用。

文件名固定、不带版本号：升级直接覆盖同名文件，桌面快捷方式永久有效。当前版本看窗口标题。

## 第一次打开

1. **放**：把 exe 放到元扫雷的 `Metasweeper<版本号>` 目录里（和 `replay` 同级）。不知道 `replay` 在哪的话，打开元扫雷菜单「查看 → 录像目录」（快捷键 `W`），返回上一级就是。
2. **运行**：双击运行。程序优先读取 exe 旁边的 `replay`；找不到时搜索 `%APPDATA%`、`%LOCALAPPDATA%` 下的所有 `Metasweeper*`；都没有才让你手动选一次目录，选完记住。
3. **等首次扫描**：第一次扫描要逐局重演录像，两万局约 3 分钟，底部有进度和剩余时间；之后走缓存，秒级出结果。扫描在后台进行，窗口不会假死。

阿比特的录像目录**不会自动加入**——它的安装目录里常堆着下载来观摩的别人的录像，自动收进来会把别人的成绩算成你的。要加就在「路径」里手动添加，并确认目录里的录像都是你自己的。

## 六个页签

| 页签 | 看什么 |
| --- | --- |
| 概览 | 三级别各多少局、最快时间 / 最高 3BV/s / 最高 stnb；最近完成局与 PB 的对比和涨分 |
| 每日 | 按天一行：局数、起止时刻、时间 / 3BV/s / stnb 分布；右键复制当天总结图 |
| PB 表 | 每个（级别 × BV）的最快局，一张 3BV 网格 |
| lsf | 三级别 × 三指标的 Top5，加个人 LSF 卡片 |
| 上传 | 挑范围，手动上传本地成绩 |
| 自动上传 | 开着它打局，新成绩自动传上去 |

### 每日

- 归日按**那一局的开始时刻**，跨午夜的局算在开始那天。时刻取自录像头里的时间戳，不是文件修改时间——拷贝、解压不影响。
- 中间一列是**算术平均**，与阿比特 Daily Review 同口径。级别单选，默认高级。
- 双击某一天列出当天每一局，双击某一局直接用元扫雷播放。
- **右键某一天**复制总结图或详细总结图：竖版卡片，手机竖屏一比一显示；可选仅当前级别或全部级别合并，往日也能出。详细总结是一天的复盘卡——最好一局与 PB 徽章、三指标对照近 7 个扫雷日、BV × 用时散点（带 PB 线）、最快 5 局与节奏分段。

### PB 表

- 三个级别合成一张纵向滚动的 3BV 网格：行是 BV 的十位段，列是个位，一格一个 BV。没打过的段整行留着，哪一段断着一眼可见。
- 格子数值可切时间 / 3BV/s / stnb / 全国名次；颜色表示这个 BV 你在**全国**的位置，未登录时退到本地 3BV/s 三分位。
- 点一格看详情（含这条纪录「保持 N 天 · 破上条用 M 天」），双击用元扫雷播放这一局。
- 搜索只给命中的格子**描边**，不隐藏其他格子——隐藏会让网格出现假断层。

### lsf

- 三级别 × 时间 / 3BV/s / stnb 的 Top5，默认按官方 BV 门槛过滤（初级 10 / 中级 30 / 高级 100，页面上可改），口径见 [top 榜与 LSF 榜](../top-lsf.md)。
- 页顶卡片是个人 LSF、定阶与等价 et；「明细」看每一项由哪五局撑着，还有只取最好 1 / 5 / 25 局的三档 LSF——三档越接近，水平越稳。
- 登录后三张表把网站 top 榜一并纳入，来源列标「本地 / 网站 / 两边」。
- LSF 参照默认实时跟随网站锚点；要复现离线大表口径，在「设置」里切到「固定基准」（内置赛季锚点）。

## 统计口径

- **只统计标准模式**。无猜、强/弱可猜、win7、upk、自定义盘面等录像一条都不进统计；非完成局不算。
- **同一局存了多份只算一局**：按文件字节完全相同判定重复（阿比特的破纪录导出、归档副本常与正本逐字节相同）。磁盘上一个文件都不动。
- **两张榜**：全 PB 不限风格取最快；NF PB 只在 [NF](../minesweeper/terminology.md) 局里取最快。FL 不单独成榜，只在风格列标注。
- 登录后 PB 表把网站 PB 一并纳入，每格取本地和网站中更快的，来源列标「本地 / 网站 / 同速」。
- **强无猜是例外**：不进统计，但可以单独上传（网站有独立的榜），见[自动上传](#自动上传)。

## 上传

第一次在「上传」页点「登录…」，输本站账号、密码与验证码。勾上「保持登录 90 天」，之后不必再输密码。

- 范围多选叠加：PB（全 PB / NF PB）、top 榜（全 PB / NF PB）、全部完成局。登录后本地比网站 PB 慢的自动排除出范围。
- **不会重复传**：按网站自己的去重口径与网站已有录像逐个比对，命中的标「网站已有」。
- **标识不符在本地提前拦**：录像标识与账号「标识管理」里登记的不完全一致（空格、全角半角都算不同）时标「标识不符」——传上去也不进任何榜单，按[扫雷标识](../identifier.md)改对再传。
- 上传前弹确认框，列出这一批的级别 / 时间 / BV / 大小 / 文件名。
- 单条失败自动重试；中途关掉程序，重开后已成功的不重传。只有账号级问题（登录失效、额度满等）才停整批。
- 「含阿比特录像」勾选框决定 `.avf` 参不参与这次上传，默认勾上。

## 自动上传

开着这一页打局，新成绩落进目录一两秒内就被发现，符合勾选范围就传走。全程不弹窗、不抢焦点——元扫雷在前台跑的时候，一个弹窗就能毁掉这一局。

- 三个独立开关：涨分局（能刷新网站 top 榜的局，需登录）、全 PB、NF PB，默认开前两个。
- 开关打开**之前**的成绩不补传；关机期间打的局，下次启动会补上。
- 只传元扫雷的 `.evf`；标识不符、会被冻结的局不传——传上去也不进榜，只白占额度。
- 账号级问题只暂停不弹窗；网络连续失败等几分钟再试。最近 100 条记录在这一页。
- **强无猜单独设置**：在「设置 → 强无猜上传」里选关闭 / 进榜才传 / 全部上传。「进榜才传」对照网站强无猜榜的六格（初 / 中 / 高 × 时间 / 3BV/s），只有刷新或填空某格才传；NF 局另对照 NF 榜。

## 数据存在哪

运行期数据都在 exe 同目录的 `YuanshenToolbox-data\` 里：设置、加密保存的账号、上传台账、扫描缓存、日志。删掉这个文件夹即回到全新状态。exe 放在不可写的位置（如 `C:\Program Files`）时，数据落到 `%APPDATA%\YuanshenToolbox\`。

账号密码与会话 Cookie 用 Windows DPAPI 加密落盘，绑定当前 Windows 用户与本机，换一台机器解不开。日志不含密码、验证码和 Cookie。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 成绩算错了，或刚打了新局 | 点「重新扫描」；仍不对就在「设置 → 诊断…」里清空扫描缓存后重扫 |
| 上传后网站显示 `d`（标识不符） | 按[扫雷标识](../identifier.md)把录像标识与账号登记改一致再传 |
| 上传中途停了 | 已成功的不受影响，恢复后点「重试失败」只补传剩下的 |
| 程序崩溃了 | 数据目录 `logs\crash-<时间>.txt` 有完整错误信息，报问题时带上它 |
| 想报问题 | 「设置 → 诊断…」→「导出诊断包…」，zip 含系统信息、配置和日志，不含凭据密文 |
