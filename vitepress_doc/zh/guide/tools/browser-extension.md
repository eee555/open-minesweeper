# 浏览器扩展（元神助手）

元神助手是为 [开源扫雷网](https://openms.top) 玩家提供辅助功能的第三方浏览器扩展，不是网站官方产品。

- **搜索用户**：通过中文实名、用户名、英文名、拼音或数字 ID 查找玩家。
- **自动上传录像**：监视本地录像文件夹，按周期上传新录像。
- **成绩分析**：查看 PB 表、前端成绩和「赛博大表」，也可分析本地 CSV 文件。

[项目主页](https://github.com/LockhartANR/yuanshen-helper) · [下载最新版本](https://github.com/LockhartANR/yuanshen-helper/releases/latest)

## 支持平台

Chrome 120 及以上桌面版。Edge 等 Chromium 浏览器通常也可加载，但未专门测试。

## 安装与更新

1. 从上方下载页获取 `yuanshen-helper-<版本>.zip`，解压到固定文件夹，之后不要移动或删除它。
2. 在 Chrome 地址栏输入 `chrome://extensions`，打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择解压后的文件夹。
4. 点浏览器工具栏的拼图图标，将「元神助手」固定到工具栏。

更新时，用新版文件替换原文件夹内容，在扩展管理页点「重新加载」，并刷新已打开的分析页和 openms.top 标签页。下载页提供 SHA-256 校验值，可按需核对。

## 使用方法

1. **首次同步**：点扩展图标，再点「同步」或「立即同步」，等待完成。
2. **搜索玩家**：输入名字片段或数字 ID，点击结果打开玩家主页。支持 `↑` / `↓` 选择、`Enter` 打开、`Esc` 关闭。
3. **成绩分析**：点搜索结果右侧的图表按钮，或窗口顶部的「我的成绩」。只分析本地文件时，点「本地 CSV 分析」。
4. **自动上传录像**：先登录 openms.top，再打开「自动上传」页，点「选择目录」并允许读取录像文件夹。选「只上传新录像」或「补传已有录像」，点「开始监视」。
5. **设置**：点右上角齿轮，可管理同步、开关站内「赛博大表」入口、填写自己的站内 ID 或清空本地数据。

## 注意事项

- 关闭上传页或最小化不会主动停止监视；结束使用时请点「暂停」。关闭所有浏览器窗口、退出浏览器或录像目录被移动、删除时，监视会停止。重启浏览器后需重新点「开始监视」；登录和权限异常按页面提示处理。
- 用户资料、成绩分析数据和上传记录保存在本机。开启自动上传后，录像发送到 openms.top，不会发送到其他第三方服务器。
- 扩展会在本机保存站内用户的实名信息，请勿在共用电脑上使用，并遵守站点规则。
