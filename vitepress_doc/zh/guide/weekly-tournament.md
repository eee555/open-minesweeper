# 打卡赛

打卡赛由开源扫雷网官方举办，分为竞速打卡赛和效率打卡赛。同一周可分别参加两种比赛，需分别注册并使用各自的[比赛标识](./identifier.md#tournament-token)。

报名前需要填写实名或被已认证玩家认证，详见[扫雷比赛](./tournament.md)。

## 比赛规则

**竞速赛和效率赛各有独立的两小时参赛时段，两个时段可以错开，也可以重叠，不必同时参加。**

比赛开始于周一0:00UTC，结束于周日24:00UTC。您可在区间内为每场比赛分别选择两小时。比赛进行期间，您可以在对应比赛页面进行注册并获得唯一比赛标识，并在此后有两小时的时间上传比赛录像。如果您在周日22:00UTC之后注册，则您的比赛结束时间依然是周日24:00UTC，请注意。

确认注册后，本场个人两小时窗口立即开始，不能自行撤回或重新选择。误操作且没有比赛录像时，须等个人窗口结束后联系主办方或管理员重置；整场比赛必须仍在进行。

比赛只统计已审核通过的录像，扫雷软件须支持比赛标识。

### 竞速打卡赛

每周只有一场竞速打卡赛，由管理员创建时选择赛制，比赛名称会显示对应前缀：

| 赛制 | 计分录像 |
| --- | --- |
| 经典 | 标准模式，包括 NF |
| NF | 标准模式，且有效右键为 0 |
| 强无猜 | 强无猜模式，包括 NF |
| 强无猜NF | 强无猜模式，且有效右键为 0 |

四个赛制均取用时最短的 2 局高级和 5 局中级，求和为成绩。中级须低于 60 秒，高级须低于 240 秒；不足局数按相应上限补足。强无猜不同于竞速无猜。

积分和历史最好成绩按本场赛制分别累计，符合 NF 条件不会额外计入另一赛制。比赛积分总榜显示合并后的竞速总积分；竞速榜同时显示四个赛制各自的总积分和最好成绩。

### 效率打卡赛

只统计标准模式（包括 NF）的录像。

每局按 `Time / IOE²`（即用时除以 IOE 的平方）计分，越低越好。取最低的 2 局高级和 5 局中级之和；中级须低于 60，高级须低于 240，不另设 IOE 上限。不足局数分别按 60、240 补足。

## 结算与取消资格

最终成绩最早在整场结束一小时后统计，这一小时不延长参赛或上传时间。已颁奖后，只有本场主办方能因违规取消选手资格；积分将撤回，录像文件保留。

## 积分奖励
比赛结束后，根据排名获得积分，公式是`50/排名`，例如第一名获得50分，第二名获得25分，以此类推。
