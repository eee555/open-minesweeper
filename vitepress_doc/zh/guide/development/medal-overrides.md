# 管理员勋章决定

管理员页面位于 `/#/staff/medals`，标签为“勋章管理”。加载玩家 ID 后核对用户名，选择勋章、操作和原因。

## 优先规则

- **强制发放**：选择合法档位与授予日期。该玩家的这一枚勋章锁定在指定档位；之后成绩更好也不自动升级，成绩失效也不自动降档或撤销。
- **禁止发放**：立即撤销当前授予，并阻止之后的自动重授。玩家尚未获得也可以提前设置。
- **恢复自动判定**：解除人工决定，先撤下人工结果，再由后台任务按真实数据重新计算。任务未完成时可能暂时显示未获得。人工纪念没有自动判定器，解除后不会自行发回。

人工决定针对 `(玩家, 勋章代码, scope_key)`。普通勋章的届次/范围必须留空，防止误建另一枚授予而重复计分。按次人工纪念和赛事类型允许填写范围；已有比赛授予应使用原记录的范围，不能把不同届次混在一起。

管理员指定的阶段不改写真实成绩进度，因此不会让其他复合勋章连带达成；禁止某枚子勋章也不会连带禁止已经满足真实条件的复合勋章，如需禁止须分别设置。后台仍维护自动进度。全局停用控制公开展示，即使有强制发放也会隐藏；人工记录继续保留，停用或删除定义后仍可解除。

发放时只能选择当前定义中的合法档位；阈值后来改变不会解除人工锁定。计分仍按当前定义计算，如果锁定的旧档位已经从阈值表删除，该档位的分数为 0。恢复自动后按最新阈值重算。

所有操作要求管理员登录和非空原因。每次变更记录操作者、动作、范围、档位、授予日期与时间；恢复自动不会删除历史。管理页显示该玩家最近 50 条记录。多位管理员的决定按提交顺序生效，后提交的决定替换前一个，历史保留。管理员写入和后台评估使用同一玩家行锁，防止并发覆盖。

本页处理现有勋章定义，不提供定义创建或全站停用的编辑器。个人主页不会公开操作原因或管理员历史。

当前自动评估器覆盖原始股东、新手、个人最佳和三阶复合。其他尚未实现自动规则的类型与纯人工纪念一样，恢复自动仅解除覆盖并撤下人工结果，不会凭空产生自动授予。

## 数据库部署

本功能新增 `MedalOverride` 和 `MedalOverrideLog`，迁移由 Django 自动生成。仓库忽略 `migrations/*.py`，部署环境须按项目惯例先生成迁移，再检查计划。

```powershell
cd E:\Tools\saolei_website\back_end\saolei
.\.venv\Scripts\python.exe manage.py makemigrations medal
.\.venv\Scripts\python.exe manage.py migrate medal --plan
.\.venv\Scripts\python.exe manage.py migrate medal
```

应用迁移后再启动新版网站和 `manage.py db_worker_robust`。原始数据中此前已经手动修改过的授予不会被自动推断为新覆盖；如需持续锁定，管理员应在管理页重新明确设置。这避免把普通撤销误认成永久禁发。

## 回归测试

后端测试验证权限、非法输入、历史、范围隔离，以及人工决定与自动刷新之间的优先关系：

```powershell
cd E:\Tools\saolei_website\back_end\saolei
.\.venv\Scripts\python.exe manage.py test medal --keepdb --noinput
```

前端接口与提交条件的单元测试：

```powershell
cd E:\Tools\saolei_website\front_end
npm.cmd run vitest -- --run src/services/staffMedalService.test.ts src/services/medalService.test.ts
```

管理页面及个人勋章页的组件测试已维护，按项目约定由用户选择执行：

```powershell
cd E:\Tools\saolei_website\front_end
npx.cmd cypress run --component --browser chrome --headless --spec "src/views/StaffView/Medal.cy.ts,src/views/UserView/UserMedals.cy.ts"
```

手动验收建议使用专用测试账号：

1. 普通用户访问管理页或直接调用管理接口，应被拒绝；管理员可看到包含隐藏与停用项的目录。
2. 为一枚能力勋章强制发放指定档位，核对个人页。上传更好成绩、冻结证据、触发历史补发后，人工档位仍不变。
3. 对另一枚尚未获得的勋章设置禁止发放，再准备满足条件的录像并重算，仍不能获得。
4. 点击恢复自动，待工人完成后重新加载，确认结果回到真实成绩对应档位。操作历史仍包含先前决定和恢复动作。
5. 为不同玩家或不同届次设置决定，确认互不影响。强制发放单个难度的勋章，不应伪造真实进度来触发三阶复合勋章。
6. 修改选择的玩家时延迟旧请求，旧结果或旧失败不得覆盖新玩家；操作进行时不要将返回结果应用到另一个玩家。

恢复自动后的结果依赖任务工人。当前页面没有跨浏览器实时通知；管理员操作后目标玩家可重新加载个人页查看。
