# 录像表达式参考

本页列出网站原生录像播放器，以及录像分析页中计数器、自定义事件的表达式能力。第三方播放器不适用。三种场景均使用 `expr-eval` 语法，字段范围和结果要求不同。

## 三种场景

| 项目 | 录像播放器 | 录像页计数器 | 录像页自定义事件 |
| --- | --- | --- | --- |
| 位置 | 原生弹窗播放器的自定义计数器 | 录像分析页的数值计数器；数据轨道引用其结果 | 录像分析页的自定义事件行 |
| 取值来源 | 播放位置对应的录像 getter | 原生事件快照和整份录像的静态数据 | 与计数器相同的字段来源 |
| 最终结果 | 转成文本显示；可拼接数字和字符串 | 必须是单一数字，允许 `NaN`、正负无穷 | 必须是布尔值、数字或字符串 |
| 求值时机 | 播放位置更新时 | 按每行选择的采样模式求值 | 连续采样：每毫秒取最后一个原生事件 |
| 两次采样之间 | 不使用录像页的采样插值 | 数值按时间线性插值；范围外保持最近端点 | 按采样结果判定事件，不插值真假 |
| 显示格式 | 在公式中使用 `toFixed`、`roundTo` 或字符串拼接 | 在独立 format 输入框使用 `d3-format`，默认 `.3f` | 颜色和 marker/line 样式；没有数值 format |
| 错误 | 显示错误内容 | 在数值格子显示错误内容 | 解析、求值错误或非法类型均视为未发生 |
| 差分 `d` | 不支持 | 支持，前驱由该行采样模式决定 | 支持，前驱由连续采样决定 |

自定义事件使用 JavaScript 原生真假判断：`true`、非零数字和非空字符串表示发生；`false`、`0`、`-0`、`NaN`、空字符串表示不发生。正负无穷表示发生，`"false"`、`"0"`、仅含空白的字符串也表示发生。数组和函数等其他类型均不发生。

时间轴和棋盘采用相同的事件悬停提示：脉冲显示事件时间及该时刻表达式得到的数字或字符串，布尔结果只显示时间；持续事件显示完整起止时间和持续时间，不受显示范围裁剪影响。时间以秒显示，保留三位小数。

自定义事件的“棋盘标记大小”仅影响棋盘图层；时间轴标记固定为 8px，形状、颜色和不透明度仍跟随事件设置。

棋盘自定义事件图层在新配置中默认开启并选中 `pluck`。悬停在脉冲标记上可查看时间和值（布尔值不显示）；悬停在持续事件轨迹上可查看完整起止时间和持续时间，即使当前只显示部分轨迹。已有保存的图层设置不被默认值覆盖。

连续采样包含所有原生事件类型，每毫秒采样一次；有事件时取该毫秒最后一个，无事件时沿用此前最近原生事件的全部字段，包括 `time`。采样时间戳使用当前毫秒，但 `time` 保留来源事件的原始时间。计数器的按键/局面变化模式先筛选符合条件的事件，再保留每毫秒最后一个符合条件的事件，不补齐空白毫秒。自定义事件不随计数器行的模式改变。

## 支持的字段

“支持”指可以直接作为变量名使用；“—”表示不可直接使用。字段名称区分大小写。计数器和自定义事件的动态值来自采样事件，静态值属于整份录像；播放器读取其当前 getter 原值，不补为 0。以下字段之外的变量（包括 `currentMs`、`current_time`、`timeMs` 和 `bvs`）不支持；计数器行 key 和事件 key 也不会成为其他公式的变量。

### mouse_state 编码

| 值 | 状态名 | 含义 |
| --- | --- | --- |
| 1 | `UpUp` | 左右键均抬起 |
| 2 | `UpDown` | 左键抬起，右键按下 |
| 3 | `UpDownNotFlag` | 左键抬起，右键按下，且没有标雷或取消标雷 |
| 4 | `DownUp` | 左键按下，右键抬起 |
| 5 | `Chording` | 左右键均按下，双击状态 |
| 6 | `ChordingNotFlag` | 左右键均按下，先在不能右击的格子上按下右键 |
| 7 | `DownUpAfterChording` | 双击后先抬起右键，左键仍按下 |
| 8 | `Undefined` | 未初始化 |

`DownUp` 等状态名不是表达式常量；请使用数字，例如 `mouse_state == 4`。

## 运算与语法

三种场景的以下运算均可使用，但计数器的**最终结果仍必须是数字**。数组、字符串和布尔值可作为中间结果。表格按大致由高到低的优先级排列，不确定时使用括号。

| 运算或语法 | 含义与示例 | 录像播放器 | 录像页计数器 | 自定义事件 |
| --- | --- | --- | --- | --- |
| `(...)` | 分组，例如 `(left + right) / time` | 支持 | 支持 | 支持 |
| `f(...)`、`a[i]`、`x.y` | 函数调用、从 0 开始的索引、属性读取，如 `[left, right][0]`、`[left, right].length`；不会绕过变量白名单 | 支持 | 支持 | 支持 |
| `[a, b, ...]`、`"text"`、`'text'` | 数组及字符串字面量 | 支持 | 支持 | 支持 |
| `x!` | 后缀阶乘，`5!` 为 120；不是逻辑非 | 支持 | 支持 | 支持 |
| `x ^ y` | 乘方，`2 ^ 3` 为 8；不是异或 | 支持 | 支持 | 支持 |
| `+x`、`-x`、`not x` | 转数字、取负、逻辑非；一元数学函数见下表 | 支持 | 支持 | 支持 |
| `*`、`/`、`%` | 乘、除、取余 | 支持 | 支持 | 支持 |
| `+`、`-` | 数值加、减；`+` 不是字符串拼接 | 支持 | 支持 | 支持 |
| `x \|\| y` | 拼接字符串；两侧均为数组时拼接数组，不是逻辑或 | 支持 | 支持 | 支持 |
| `==`、`!=`、`<`、`<=`、`>`、`>=` | 比较，例如 `left > right` | 支持 | 支持 | 支持 |
| `x in a` | 是否属于数组，例如 `mouse_state in [4, 5, 7]` | 支持 | 支持 | 支持 |
| `x and y` | 逻辑且；左侧为假时不计算右侧 | 支持 | 支持 | 支持 |
| `x or y` | 逻辑或；左侧为真时不计算右侧 | 支持 | 支持 | 支持 |
| `c ? a : b` | 条件表达式，只计算选中的分支，支持嵌套 | 支持 | 支持 | 支持 |
| `a; b` | 顺序求值并返回最后一个结果，不是变量声明 | 支持 | 支持 | 支持 |
| `x = value` | 赋值 | 不支持 | 不支持 | 不支持 |
| `f(x) = expr` | 定义函数 | 不支持 | 不支持 | 不支持 |
| `if (...) { ... }`、`&&`、`!x`、`**`、`===`、`=>` | JavaScript 语句/运算符或箭头函数；不是这里的语法 | 不支持 | 不支持 | 不支持 |

`and`、`or`、`not` 使用关键字，逻辑结果是布尔值；计数器需要数值时使用 `条件 ? 1 : 0`。也支持科学计数法，例如 `1e-3`。括号建议写全，如 `sin(time)^2`，避免一元函数省略括号时的优先级歧义。

### 常量

| 常量或写法 | 含义 | 三种场景 |

| `PI` | 圆周率 | 支持 |

## 函数

以下为当前内置函数、应用扩展和可写成函数形式的一元运算，支持范围见表格。`x`、`a`、`f` 等表示参数占位符，不是新增的录像字段。角度均以弧度为单位。

播放器需要保留小数末尾的 0 时使用 `toFixed`；它返回文本，`roundTo` 仍返回数字。新默认公式保留三位小数，已保存的公式不自动改写，可将显示用的 `roundTo` 换为 `toFixed`。分析器计数器继续使用独立的 format（如 `.3f`）。

`map`、`filter`、`fold` 的函数参数可以使用兼容的内置函数；不支持 JavaScript 箭头函数或在公式里定义新函数。没有通用的 `String`、`Number`、`isNaN`、`isFinite`、`Math.*` 函数：转数字使用一元 `+`，拼接文本使用 `"" || value`，检测 `NaN` 可使用 `value != value`，其中 value 应替换为实际字段或表达式。`d` 必须直接调用，不作为这些数组函数的回调。

### 差分规则

| 规则 | 说明 |
| --- | --- |
| 差分对象 | 可以是字段或数值表达式，如 `d(left)`、`d(left + right)`、`d(bbbv_solved) / d(time)` |
| 默认步长 | `d(expr)` 等价于 `d(expr, 1)`；按保留的采样点数量计数，不是毫秒数或原生事件数量 |
| 步长表达式 | n 在当前采样点求值，如 `d(left, time > 1 ? 2 : 1)`；非正整数会报错 |
| 前驱不足 | 返回 `NaN`；计数器保留该数字，自定义事件判为未发生 |
| 嵌套差分 | 支持 `d(d(left))`、`d(d(left, 2), 3)`；前者前两点、后者前五点为 `NaN` |
| 不自动归一化 | 差分不自动除以步长或时间差；需要速率时显式除以 `d(time)` |
| 求值顺序 | 先筛选、合并毫秒采样点，再求差分；计数器之后才插值和格式化 |
| 条件分支 | 分支跳过某次差分调用不会改变“上一采样点”的含义 |

## 默认计数器

首次使用时，计数器默认采用连续采样、`.3f` 显示格式：

| key | 表达式 | 默认 Plot |
| --- | --- | --- |
| `Bvs` | `d(bbbv_solved, 1000) / d(time, 1000)` | Plot 1 |
| `Ces` | `d(lce+rce+dce, 1000)/d(time, 1000)` | Plot 1 |
| `Mov` | `d(path, 1000) / d(time, 1000) / 16` | Plot 2 |

这里的 1000 表示连续采样的 1000 个毫秒采样点；分母使用原始事件 `time` 的差值。开头不足 1000 点时为 `NaN`，时间差为零时也可能出现非有限值。原有小写 `bvs` 不再作为默认计数器；已保存的计数器和 Plot 配置不会被新默认值覆盖。

## 默认自定义事件

首次使用时，默认包含以下事件：

| key | 类型 | 表达式 |
| --- | --- | --- |
| `left` | 持续 | `mouse_state in [4, 5, 6, 7]` |
| `right` | 持续 | `mouse_state in [2, 3, 5, 6]` |
| `pluck` | 脉冲 | `d(pluck)` |

`pluck` 脉冲在累计值相比上一毫秒发生变化时出现；值不变或差分为 `NaN` 时不出现。已有保存的自定义事件不会被新默认值覆盖。

## 示例

| 场景 | 公式 | 效果 |
| --- | --- | --- |
| 录像播放器 | `toFixed(bbbv_s, 3) \|\| "@" \|\| bbbv_solved \|\| "/" \|\| bbbv` | 拼接固定三位小数的速率、已完成 BV 和总 BV |
| 录像页计数器 | `time > 0 ? bbbv_solved / time : 0` | 计算累计 3BV/s；独立 format 可设为 `.3f` |
| 录像页计数器 | `d(bbbv_solved) / d(time)` | 两个采样点之间的 3BV/s，首点为 `NaN` |
| 自定义脉冲事件 | `d(left) > 0` | 在累计左键点击数增加的毫秒产生脉冲 |
| 自定义持续事件 | `mouse_state in [4, 5, 6, 7]` | 选择左键处于按下状态的连续事件段 |
| 自定义事件 | `mouse_state == 4 and d(left) > 0` | 同时满足鼠标状态和点击增量条件 |
