# 作品页

[进入作品页](https://openms.top/#/works)

作品页展示本站收录的扫雷作品：B 站视频、B 站专栏和扫雷网帖子。**只有审核通过的作品才会出现在这里**。默认按《实时热度》排序，点击表头可切换《发表时间》《实时热度》《累计投喂》，切换后回到第一页，每页 20 条。B 站视频点标题可在站内预览，其它作品点标题打开原链接；标题前的图标标明来源平台。

如果你打算把自己的创作推广到这里，下面几条规则最容易踩坑：

- 投稿前必须先[关联并认证](./account-links.md)对应平台的外站账号。
- 一条链接只能投稿一次，被驳回后也不能重投。
- 作品页没有删除入口，作者不能自行撤下已通过审核的作品。
- 审核中与已驳回的作品虽然不出现在作品页，但在个人主页、数据库页对所有人可见。

## 投稿

点击《作品》页右上的《投稿》，选择平台与类型，填写作品标识，语言可以留空。作品标识既可以填编号，也可以粘贴完整链接：B 站视频用 BV 号，B 站专栏和扫雷网帖子用数字 ID（前导零不影响，例如 `cv01646742` 与 `cv1646742` 是同一篇）。标题和发表时间由来源网站自动获取，不需要填写。

::: tip 来源网站暂时打不开时
投稿仍会保留，标题显示《标题待补全》，由管理员审核时补录标题并核验外站账号。链接本身无效、类型选错或格式不对时投稿会被拒绝，不会留下记录。
:::

### 投稿前需要关联账号

本站会核对来源作品的作者，与你**已认证**的账号关联是否属于同一人；没有关联、关联未认证，或作者不一致都无法投稿。外站作者 ID 只用于核对归属，不会保存在本站，也不会显示在作品页。

B 站视频与专栏对应哔哩哔哩账号，扫雷网帖子对应扫雷网账号，关联方法见[账号关联](./account-links.md)。**自媒体账号关联是公开的**：一旦推广作品，外站账号就与本站身份公开对应；如果不打算推广作品，没有必要关联，也不建议关联。

::: warning 一条链接只能投稿一次
同一条外链不能重复投稿，**即使被驳回也不能重新投稿**；只有管理员彻底删除该记录后，链接才会被释放。投稿前请确认链接和类型选对。
:::

## 审核与可见范围

| 位置 | 能看到什么 |
| --- | --- |
| 作品页 | 只有审核通过的作品 |
| 个人主页《作品》、数据库页《作品》 | 所有状态，含审核中、已驳回；已驳回还会显示驳回理由和驳回人，所有访客都能看到 |
| 排行榜《作品》 | 只统计审核通过的作品，按作者汇总，不是单条作品榜 |

作品页没有《审核中》入口；投稿后请到自己的个人主页《作品》查看状态。审核期间作品不进入作品页和排行榜；通过审核时会按作品已有的投喂数一次性计入。

::: warning 作者不能自己删除作品
审核通过前想撤下作品，只能联系管理员驳回；通过审核后作品即为最终状态，标题等信息也不能再修改。只有管理员可以彻底删除已通过审核的作品，删除后该链接才可重新投稿。
:::

## 投喂与热度

登录后可在《累计投喂》一列点击《投喂》，每次消耗 1 个红宝石。红宝石按注册时长累积，每满 24 小时获得 1 个，与是否登录无关，不使用也不会过期；鼠标停在按钮上可查看余额。

- **实时热度**：每次投喂约 +1，之后每过一天保留 99%，连续衰减，因此老作品会自然下滑。
- **累计投喂**：累计次数，不随时间衰减；作品被驳回时清零。

每个账号每天最多成功投喂 10 次，按 UTC 自然日计算（北京时间早上 8 点重置）；失败的投喂不计数。给自己的作品投喂也是允许的。

::: warning 驳回会退还红宝石，但不退还当日次数
作品被驳回时，投喂消耗的红宝石会退还，但当天已经用掉的投喂次数不会退回。
:::

## 常见问题

### 投稿后为什么在作品页找不到？
作品需要管理员审核通过后才会出现在作品页。到个人主页《作品》查看状态；显示《已驳回》时可以看驳回理由。

### 为什么提示《该作品已投稿过》？
同一条外链已有投稿记录（包括被驳回的记录）。不能重复投稿，也不建议用改写链接格式的方式绕过。

### 为什么标题是《标题待补全》？
投稿时来源网站未能读取标题，管理员审核时会补录。若来源网站一直不可用，管理员也会核验外站账号归属。

### 投喂后为什么排名没变？
《实时热度》每天衰减 1%，不同作品的投喂时间也不同；按《累计投喂》排序看到的是不衰减的次数。作品页的排序在下次刷新时更新，可用右上角的刷新按钮重新拉取。

### 关联了账号还是不能投稿？
检查关联是否已通过管理员认证，以及作品作者是不是同一个外站账号。详见[账号关联](./account-links.md)。
