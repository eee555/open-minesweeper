# 勋章系统

勋章用来记录你在本站达成的目标，称号就是这枚勋章对应的名字。**达到条件后，系统自动发放；获得后，你可以挑选最多 6 枚佩戴，展示在个人主页。**

## 先从这里开始

1. 打开个人主页，进入《勋章》选项卡。
2. 在《全部勋章》和《已获得勋章》间切换。每行展示当前档、下一目标和完整档位；左右浏览阶梯，点击档位或《详情》查看条件。
3. 登录后，在自己的勋章页打开《管理佩戴》，加入想展示的勋章，再点击《保存佩戴》。

《全部勋章》包含公开的未获得目标，《已获得勋章》只显示当前有效授予；隐藏且未解锁的勋章不展示。还没有勋章时，可以先完善实名资料、上传自己的录像，并确认录像通过审核。

## 如何获得勋章

### 新手称号：从资料和第一条录像开始

- **实名在册**：已填写实名，账号不再处于“匿名”状态。
- **录像过审**：名下至少有一条已通过审核的录像。
- **扫雷新秀**：初级、中级、高级各有至少一条已通过审核的录像。
- **盲扫新秀**：初级、中级、高级各有至少一条已通过审核的盲扫录像。
- **走马观花**：勋章要求的每种开放模式各有已通过审核的录像。不同模式和不同难度是两回事，只集齐三个难度不能完成这个目标。
- **旧迹新篇**：扫雷网账号关联已通过认证。操作方法见[账号关联](./account-links.md)。当前以关联认证结果为准，不要求重新导入录像；扫雷网迁移期间，资料刷新与录像同步已关闭。

新手称号中的录像条件按各自要求统计，不必都使用标准模式。

### 能力称号：用成绩跨过固定门槛

能力称号分别记录初级、中级、高级的表现：

- **破境**看最快时间，越短越好。例如“初级破境·Sub10”表示初级用时严格小于 10 秒，10.000 秒不算。
- **神速**看最高 3BV/s，也就是每秒完成的局面工作量，越高越好。例如“高级神速·3”表示高级 3BV/s 达到或超过 3。
- **通明**看最高 STNB，越高越好。它是综合评价单局表现的指标，不是局数或排名。
- **盲扫破境、盲扫神速、盲扫通明**分别看盲扫录像中的时间、3BV/s 和 STNB。
- **盲扫精工、标旗精工**看对应玩法的最高 thrp，也就是 `3BV ÷ 有效点击数`，越高越好。thrp 与使用总点击数计算的 IOE 不同，不能直接拿 IOE 对照档位。
- **三阶盲扫精工、三阶标旗精工**要求初级、中级、高级在同一种玩法下都达到该档要求。“三阶”指三个难度，不是三局、三次获奖或三项成绩相加。例如三阶盲扫精工·0.9 要求三个难度的盲扫 thrp 分别达到或超过 0.9，可以由不同录像完成。

这些称号比较的是你自己的合格成绩与固定门槛。单项达到条件即可，不要求进入排行榜，也不需要凑齐五条成绩或超过其他玩家。指标的进一步说明见[扫雷数据](./minesweeper/stat.md)。

单个难度的能力勋章用一星、二星、三星区分初级、中级、高级；三星为上方一颗、下方两颗。颜色表示该难度内的成绩档次，数字表示具体门槛。不同难度的同色不代表相同用时或排行榜名次。三阶精工表达跨难度达标，不会被标成高级三星。

可在勋章页打开《自定义勋章配色》，或进入《设置》中的《勋章配色》，调整五个色档，也可以给某个门槛单独设色。修改只影响你看到的颜色，自动保存在当前浏览器；支持恢复默认和 JSON 导入导出。

::: tip 普通、盲扫和标旗怎么区分？
盲扫通常记作 NF，标旗通常记作 FL，系统根据录像中的有效右键操作判定。普通的破境、神速、通明不限制这两种玩法，因此一条盲扫录像可能同时获得普通和盲扫称号。

精工则分开统计：盲扫录像计入盲扫精工，标旗录像计入标旗精工，同一条录像不能同时计入这两套精工称号。
:::

### 其他称号

“原始股东”记录名下仍保存在本站的最小录像编号是否早于指定门槛，反映早期录像的留存情况。它不按账号注册时间、录像拍摄时间或赞助金额判定，也不要求这条录像已经过审。

其他称号以实际开放内容和勋章注解为准。某个分类没有显示，表示当前筛选中没有可展示的条目。

## 哪些录像可以用于能力称号？

能力称号使用的录像需要同时满足：

1. **归属于你的账号**。上传文件后还要正确匹配玩家标识；显示“标识不匹配”时，先检查[扫雷标识](./identifier.md)。
2. **状态为“已通过审核”**。文件上传成功不等于已经过审，待审核、冻结等状态不能作为能力称号的有效成绩。
3. **使用标准模式，难度为初级、中级或高级**。无猜等其他模式的录像不能用于这些能力称号。
4. **已解除比赛隐藏状态**。仍被标记为进行中比赛录像的成绩暂不计入，公开后才会重新检查。
5. **具有对应的有效数据**。精工还需要有效的 3BV 和点击数据；盲扫精工不采用有效点击数小于 3BV 的异常数据。

当前这些能力称号不额外设置 3BV 下限。不同指标可以由不同录像达成，不要求在同一局里同时刷新时间、速度和效率。

旧录像也可以参与判定，前提是已经上传到本站并满足对应条件。只保存在电脑上、只在其他平台留有成绩，或仅通过 CSV 导入到页面中的本地记录，都不能直接发放勋章。

## 如何佩戴、更换和调整顺序？

1. 登录并进入**自己的**个人主页 →《勋章》。查看他人主页时只能浏览，不能替对方修改。
2. 点击《管理佩戴》，使用条目中的《加入佩戴／取消佩戴》。预览档位不会改变佩戴。
3. 最多选择 **6 枚**。选满后，先取消一枚，再选择新的勋章。
4. 点击《保存佩戴》，再到个人资料区确认展示结果。

在编辑区使用左右箭头调整展示顺序，点击《保存佩戴》后生效。

佩戴的勋章会出现在个人主页的资料区，宽屏时通常在左侧，窄屏时在上方，切换 Top、PB、纪录等选项卡仍可看到。在排行榜等使用玩家名字提示的地方，鼠标悬停名字也可以查看对方佩戴的勋章，再移到勋章上查看说明。

::: tip 获得与佩戴是两回事
获得后需要自己选择并保存，才会出现在佩戴展示中。取消佩戴不会失去勋章；全部取消后保存，可以清空佩戴栏，但别人仍可在你的《勋章》页看到已获得的勋章。

编辑区的左右箭头可以调整顺序，《取消修改》恢复已保存选择。加入或移除只是修改待保存的选择。若出现“佩戴没有保存”，请检查登录状态和网络后重新保存，并确认展示结果。
:::

## 勋章会怎样升级或变化？

同一系列、同一难度、同一玩法只保留当前达到的最高档。例如从“初级破境·Sub20”升到“初级破境·Sub10”后，会显示 Sub10，不会额外保留一枚 Sub20。已经佩戴的这枚勋章会随档位更新，普通与盲扫、不同难度仍是不同的勋章。

自动发放的勋章依赖当前有效资料和成绩。录像被删除、退审、冻结或改归其他玩家，或者相关资料、账号关联发生变化后，系统会重新检查条件。有其他合格成绩时会按它们保留或调整档位；不再满足条件时，可能降档或收回，并从佩戴展示中消失。

管理员人工发放或禁止发放的勋章，按管理员决定处理。人工固定档位后，后续成绩不会自动改变这一档；如需恢复自动判定，请联系管理员。勋章被全站停用后也不会继续公开展示。

## 常见问题

### 上传后已经达标，为什么还没有勋章？

先在个人主页的《录像》中检查归属、审核状态、模式、难度和对应指标，特别留意“上传成功”和“已通过审核”的区别。无猜成绩、仍处于比赛隐藏状态的录像，也不能用于能力称号。

勋章由后台任务更新，上传、过审或修改标识后可能需要等待。稍后刷新页面再查看即可，不需要为了获得勋章重复上传同一条录像。若仍然异常，请联系管理员，并提供本站用户 ID、录像 ID 或链接、预期获得的称号。

### 显示“历史勋章正在补发”，怎么办？

首次查看时，系统会安排检查已有资料和历史录像。页面会尝试自动更新；如果提示一直保留，可以稍后点击《重新加载》。这表示还在等待补发结果，不代表已有成绩被清空，也不要求重新上传历史录像。

### 获得了勋章，为什么名字提示或佩戴栏没有显示？

先确认已选中并点击《保存佩戴》。勋章页显示已获得的勋章，佩戴栏和名字提示只显示你选择展示的勋章。其他已打开的页面可能暂时保留旧结果，稍后刷新即可。

### 为什么没有“下一档”？

一次性称号不需要升级；分档称号达到当前最高档后，也不会再提示下一档。勋章上的数字表示已达到的档位，不一定等于你的精确最好成绩。
